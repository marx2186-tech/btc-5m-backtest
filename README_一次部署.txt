BTC/加密货币自主回测机器人——一次部署版

用途
====
完成一次上传后，后续不再反复替换 backtest.py。ChatGPT 可通过 GitHub Issue 提交 JSON 请求，GitHub Actions 自动下载官方K线、审计、搜索多组种子、样本外验证、保存逐笔交易并把最终报告回复到 Issue。

最后一次部署
============
1. 将本压缩包解压。
2. 在当前 GitHub 仓库选择 Add file -> Upload files。
3. 一次性拖入压缩包内全部文件和文件夹，覆盖同名 requirements.txt。
4. Commit changes。

之后的使用
==========
用户只需在聊天中描述回测目标。ChatGPT 创建标题以 [BACKTEST] 开头的 GitHub Issue，正文写入 JSON。工作流自动执行，结果写入 results/ 和 history/，并回复到该 Issue。

默认验收
========
BTCUSDT 永续，5分钟，2026-05训练、2026-06样本外验证；每月20-30笔；胜率>=70%；实际平均盈利/平均亏损>=1.5；单边手续费0.05%；每次成交2个最小跳动滑点；同一信号一笔完整交易；同K止损优先。

重要说明
========
系统不会伪造满足条件的结果。若搜索空间中没有通过样本外验收的策略，会返回“未达到”及最接近候选。两个月历史通过也不等于未来保证。
